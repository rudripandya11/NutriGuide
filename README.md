# 🥗 NutriGuide – ML-Based Nutrition & Lifestyle Platform

**NutriGuide** is a Machine Learning-based nutrition and lifestyle platform that provides personalized Indian meal and exercise recommendations based on user health data, dietary preferences, lifestyle, and fitness goals.

## ✨ Features

- 🍱 Personalized Indian meal recommendations
- 🧠 **XGBoost-based** food recommendation
- 🔥 BMI and TDEE calculation
- 🏃 Personalized exercise recommendations
- 📊 Calorie and nutrition tracking
- 😊 Mood and craving tracking
- 👩 Female health support
- ⌚ Fitbit integration for activity and sleep data
- 🔥 Firebase-based user data storage
